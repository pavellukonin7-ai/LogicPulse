# LogicPulse 1.2 — «Запомнить меня на 30 дней»

Дополнение от 30 сентября 2026 года к существующему проекту 1.2.0.
Используйте `upgrade-remember-me.sh`, а не повторную установку `upgrade-v1.2.sh`.

## Поведение

- На страницах входа и регистрации появилась галочка «Запомнить меня на 30 дней».
- По умолчанию она выключена: срок сеанса — 12 часов.
- При включении cookie и запись сеанса в БД действуют 30 дней с момента входа.
  Срок фиксированный: посещение сайта не продлевает его бесконечно.
- В обычном браузере вход сохраняется при закрытии вкладки и браузера, если
  пользователь не очищает данные сайта. В инкогнито данные удаляются при
  закрытии всех приватных окон.
- «Выйти» удаляет cookie и отзывает соответствующий сеанс на сервере сразу.
- Пароль в браузере приложением не сохраняется: используется случайный ключ
  в Secure, HttpOnly, SameSite=Lax cookie. В БД хранится хеш ключа.
- У существующих сеансов остаётся прежний срок. Для 30 дней нужно выйти и
  войти с новой галочкой; повторно регистрироваться не нужно.
- Права user/admin не меняются. Сброс пароля администратора существующей
  командой `python -m app.manage admin` отзывает все его сеансы, включая 30-дневные.
- `POST /api/auth/token` для Swagger остаётся на 12 часов. `remember_me` применяется
  только к JSON-телам `/api/auth/login` и `/api/auth/register`, например:

```json
{"email":"person@example.com","password":"your-own-password","remember_me":true}
```

## Установка на существующий сервер

Скачайте обновлённый архив как `LogicPulse_Server_v1.2.0.zip` в Downloads.
В Windows PowerShell:

```powershell
scp -i "$env:USERPROFILE\.ssh\logicpulse_root_ed25519" "$env:USERPROFILE\Downloads\LogicPulse_Server_v1.2.0.zip" root@185.125.218.116:/root/
```

В терминале VPS под root:

```bash
python3 -m zipfile -e /root/LogicPulse_Server_v1.2.0.zip /root/logicpulse-remember-update
bash /root/logicpulse-remember-update/LogicPulse_Server_v1.2.0/scripts/upgrade-remember-me.sh /opt/logicpulse
```

Скрипт проверяет совместимость по хешам изменяемых файлов. Если они отличаются
от исходной версии 1.2 или уже применённого дополнения, он останавливается до
изменений. Это защищает локальные доработки от перезаписи.

Скрипт создаёт дамп БД и архив прежних файлов, собирает frontend и backend до
замены приложения, пересоздаёт только backend. Затем публикует собранный сайт
и выполняет проверки. При ошибке после начала замены восстанавливает прежние
файлы и образ backend. Telegram-worker продолжает работать со своим текущим
образом. `.env`, Compose, Nginx, Xray и таблицы БД не изменяются; pgAdmin и
Registry не включаются. Во время пересоздания backend возможен короткий перерыв API.

Резервная копия содержит конфигурацию и секреты, хранится у root с закрытыми правами.
Для ручного отката используйте путь архива, напечатанный установщиком:

```bash
cd /opt/logicpulse
# Укажите фактический путь из вывода установки:
lp_backup=/root/logicpulse-before-remember-YYYYMMDDTHHMMSSZ.tar.gz
tar -xzf "$lp_backup" -C /opt/logicpulse
lp_image_tag="$(docker compose config --format json | python3 -c 'import json,sys; print(json.load(sys.stdin)["services"]["backend"]["image"])')"
docker tag "$(cat "$lp_backup.image-id")" "$lp_image_tag"
docker compose up -d --no-deps --force-recreate --wait --wait-timeout 180 backend
```

Скрипт сохраняет старые хешированные файлы сайта для открытых вкладок. Для
получения новой формы после установки обновите страницу аккаунта Ctrl+F5.

## Проверка на вашем сервере

1. В обычном браузере откройте https://logicpulse.ru/account.html.
2. Если уже вошли, нажмите «Выйти» на главной странице.
3. Введите существующие email и пароль, включите «Запомнить меня на 30 дней».
4. Войдите, закройте браузер и откройте сайт снова. Вход должен сохраниться.
5. В DevTools → Application → Cookies → https://logicpulse.ru проверьте
   срок действия `lp_session`: примерно через 30 дней. Не отправляйте значение cookie.
6. Нажмите «Выйти»: аккаунт должен перестать быть авторизованным сразу.
7. Войдите без галочки: срок cookie должен быть около 12 часов.

## Проверки разработки

Тесты запускаются из каталога `backend`:

```bash
python -m pytest tests/test_remember_me.py tests/test_admin_v12.py tests/test_api.py -q
```

Они проверяют срок cookie и серверного сеанса при регистрации и входе,
сохранение входа с восстановленным cookie, границу истечения срока,
CSRF, отзыв при выходе, отказ при повторном использовании отозванного cookie,
отзыв после сброса пароля администратора, строгий тип поля и прежний срок Swagger.
Тестовая база — SQLite; production PostgreSQL и Docker-деплой в этой среде
не запускались. Итог сборки и тестов фиксируется в README дополнения.
