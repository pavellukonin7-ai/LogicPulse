# LogicPulse — Living Pulse, движение при прокрутке

Обновление существующего проекта `/opt/logicpulse`. Визуальное направление №4:
тёмный первый экран, фигура из частиц, светлый каталог услуг,
разделы подхода и проектов, форма заявки. Есть адаптация для телефона.

При прокрутке вниз фигура смещается, поворачивается и немного меняет масштаб.
При прокрутке вверх движение идёт в обратную сторону. Поле частиц внизу
движется с другой скоростью, заголовки и этапы появляются по мере прокрутки.
Прокрутка остаётся стандартной; фонового бесконечного цикла анимации нет.
На телефоне амплитуда меньше. При системной настройке «Уменьшение движения»
эффекты отключаются, все разделы остаются видимыми. Морфинг частиц и реакция
на курсор в эту версию не входят. Шрифты и SVG размещены локально.

## Посмотреть перед установкой

- `living-motion-preview/LogicPulse-scroll-demo.mp4` — движение в локальном браузере.
- `living-motion-preview/desktop.png` — компьютер, обзор страницы без движения.
- `living-motion-preview/mobile.png` — телефон, обзор страницы без движения.
- `living-motion-preview/verification.json` — результаты локальной проверки.

На превью показаны пять шаблонных услуг. После установки названия, цены,
сроки и состав работ загружаются из вашей базы. Превью не подтверждает
публикацию этих цен. Установщик не создаёт услуги и не заменяет их значения.

## Установить на существующий сервер

Для этого обновления нужен новый архив с движением; предыдущий скачанный
статичный вариант этих эффектов не содержит. Скачайте свежий архив `LogicPulse_Server_v1.2.0.zip`. Если браузер добавил
к имени `(1)` или другую цифру, переименуйте файл перед следующей командой.

**Windows PowerShell**, на вашем компьютере:

```powershell
scp -i "$env:USERPROFILE\.ssh\logicpulse_root_ed25519" "$env:USERPROFILE\Downloads\LogicPulse_Server_v1.2.0.zip" root@185.125.218.116:/root/
```

**Bash на VPS**, от root:

```bash
python3 -m zipfile -e /root/LogicPulse_Server_v1.2.0.zip /root/logicpulse-living-update
bash /root/logicpulse-living-update/LogicPulse_Server_v1.2.0/scripts/upgrade-living-pulse.sh /opt/logicpulse
```

Распаковывайте именно в отдельную папку, указанную выше. После сообщения
«Готово: Living Pulse установлен» откройте https://logicpulse.ru/ и нажмите
Ctrl+F5. Прокрутите первый экран вниз и обратно вверх. Проверьте раскрытие
услуги и выбор услуги в форме. Если движения нет, проверьте, не включено ли
«Уменьшение движения» в настройках специальных возможностей вашей системы.

Если цена или срок не заполнены: **Управление → Услуги → Изменить**.
Проверьте диапазон цены, срок, состав работ и условия. Перед публикацией
сопоставьте их с объёмом, трудозатратами и себестоимостью. Подписки на AI,
хостинг и сторонние сервисы рассчитываются отдельно.

## Как выполняется обновление

Установщик проверяет совместимость файлов, делает дамп базы и копию
конфигурации, исходников и сайта. При неизвестных локальных изменениях
он останавливается до замены файлов: пришлите текст этого сообщения.

Сначала собирается фронтенд во временной папке. Если уже установлена
статичная версия Living Pulse или полные карточки услуг, backend не требует
пересборки и перезапуска. На более ранней совместимой версии дополнение
карточек установится вместе с кратким пересозданием backend. Затем
публикуется сборка сайта и запускаются проверки. При ошибке после начала замены установщик пытается восстановить
прежние файлы и образ. При успешном обновлении путь к резервной копии
показывается в конце вывода.

В пакет включено предыдущее дополнение для полных карточек услуг: если оно
ещё не установлено, добавится таблица дополнительных полей. Данные услуг,
заявки, пользователи и сеансы не удаляются. Настройки `.env`, Docker Compose,
Nginx, Xray и Telegram не изменяются; telegram-worker не перезапускается.

## Проверки

Выполнена сборка `npm run build`. Браузерная проверка на ширинах 320, 390,
768 и 1440 пикселей: нет горизонтального переполнения, стили, шрифты и
графика загружаются без 404. Проверены раскрытие услуг, выбор в форме,
мобильное меню и навигация авторизованного пользователя. Проверены движение
фигуры и нижнего поля, обратимость при скролле вверх, отсутствие смещения
при повторной отрисовке, отключение по prefers-reduced-motion и смена
этой настройки без перезагрузки страницы.

Успех отправки, обработка ошибки и сохранение ключа повторной отправки
проверены с локальным тестовым API. Реальная заявка с этого компьютера
не отправлялась. Развёртывание Docker и доступ к вашей базе здесь
не проверялись: их проверяет установщик на VPS.

После установки при необходимости:

```bash
cd /opt/logicpulse
bash scripts/check.sh
docker compose logs --since=5m --tail=60 backend telegram-worker
```

## Ручной откат

В конце установки выводится путь вида
`/root/logicpulse-before-living-pulse-TIMESTAMP.tar.gz`.
Рядом находится файл `.tar.gz.image-id` с идентификатором прежнего образа.
Сохраните оба файла. Для отката нужно восстановить архив в `/opt/logicpulse`,
вернуть прежнему образу тег из сервиса backend в Compose и пересоздать
только backend. Если автоматический откат завершился ошибкой, пришлите
сообщение и путь к копии — команды следует подобрать по этому пути.

База при откате автоматически не восстанавливается из дампа: это сохраняет
заявки, поступившие после обновления. Дополнительная таблица услуг может
остаться; её удалять не требуется.
