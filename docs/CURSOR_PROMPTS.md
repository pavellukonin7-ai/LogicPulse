# Работа с обновлением в Cursor

Откройте удалённую папку /opt/logicpulse. Основная инструкция — START_HERE.md.

Промпт для проверки после установки:

Проверь docker compose ps, /api/health и журнал backend. БД — существующий сервис
postgres с alias db. Не меняй имена томов, пароли и сертификаты. Не запускай down -v.
Проверь GET /api/services, готовность frontend и пути /assets/*.css. Не печатай .env,
ADMIN_API_KEY, пароли или хеши htpasswd в ответе. Административные запросы требуют ключа
X-Admin-Key. Начальные диапазоны цен не публикуй без проверки владельцем.

Промпт для дальнейшей разработки:

Frontend находится в frontend/, backend — в backend/app/, конфигурация Nginx —
nginx/templates/production.conf. После изменения frontend выполни npm ci и npm run build.
Перед публикацией сохрани прежний сайт и проверь сборку. site/ содержит результат сборки.
Успех отправки формы показывай только после сохранения заявки. При сетевой ошибке
сохраняй текст и request_id для безопасного повтора. Тесты API — backend/tests/.
