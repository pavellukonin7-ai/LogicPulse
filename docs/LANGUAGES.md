# LogicPulse: русский, английский и китайский

Это инкрементальное обновление для уже работающего проекта `/opt/logicpulse` с оформлением Living Pulse.

## Что добавлено

- переключатель `RU / EN / 中文` в правом верхнем углу главной страницы, аккаунта и страницы обработки данных;
- полный перевод интерфейса на русский, английский и упрощённый китайский;
- сохранение выбора в браузере под ключом `lp_language`;
- прямые ссылки `?lang=ru`, `?lang=en` и `?lang=zh`;
- локальный китайский шрифт: сайт не зависит от Google Fonts;
- локализованные сообщения формы и кнопка показа пароля;
- сохранение заполненных полей, выбранной услуги и раскрытой карточки при смене языка.

Пять стандартных услуг переводятся по точному совпадению с шаблонами проекта. Если администратор изменил текст услуги или добавил собственную услугу только на русском, сайт честно оставляет этот текст на русском и показывает короткое пояснение. Автоматический машинный перевод пользовательских данных не выполняется.

## Установка на VPS

Распакуйте новый архив в отдельную папку, не поверх `/opt/logicpulse`, затем выполните:

```bash
bash /root/LogicPulse_Server_v1.2.0/scripts/upgrade-living-pulse.sh /opt/logicpulse
```

Установщик:

1. проверит совместимость файлов;
2. создаст дамп PostgreSQL и резервную копию проекта;
3. соберёт frontend внутри контейнера Node;
4. опубликует только после успешной сборки;
5. проверит Nginx, API и рабочий HTTPS-сайт;
6. при ошибке восстановит предыдущую версию.

База данных, услуги, заявки, аккаунты и настройки Telegram не заменяются.

## Проверка после установки

1. Откройте `https://logicpulse.ru/` и нажмите `Ctrl+F5`.
2. Нажмите `EN`, затем `中文`, затем `RU`.
3. Заполните несколько полей заявки, смените язык и убедитесь, что данные остались.
4. Откройте `https://logicpulse.ru/account.html` и проверьте переключатель и показ пароля.
5. Закройте вкладку, откройте сайт снова: должен сохраниться последний выбранный язык.
6. Проверьте прямую ссылку `https://logicpulse.ru/?lang=en`.

Дополнительная серверная проверка:

```bash
cd /opt/logicpulse
bash scripts/check.sh
docker compose logs --since=10m --tail=80 backend nginx
```

## Откат

Путь к резервной копии установщик выводит в конце. При сбое автоматический откат выполняется сам. Не используйте `docker compose down -v`: эта команда может удалить данные PostgreSQL.

## Локальная проверка выпуска

- `npm run build` — успешно;
- браузеры: 1440, 768, 390 и 320 px;
- нет горизонтального переполнения;
- CSS, JS и локальные шрифты загружаются без ошибок;
- клавиатурное переключение и 44px области нажатия проверены;
- неизвестный текст из API не подменяется;
- несогласованные цены остаются скрытыми;
- тестовая заявка использует локальный mock API и не отправляется на рабочий сервер.

Снимки проверки находятся в `docs/language-preview/`, результаты — в `docs/language-preview/verification.json`.
