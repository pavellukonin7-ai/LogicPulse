# Портфолио LogicPulse из GitHub

Обновление подключает к сайту публичные репозитории аккаунта `pavellukonin7-ai`.

## Как это работает

- браузер обращается только к `GET /api/projects` на домене LogicPulse;
- backend получает публичный список из GitHub API без токена;
- ответ кэшируется на 30 минут;
- при недоступности GitHub используется встроенная сохранённая копия;
- приватные репозитории не запрашиваются и не публикуются;
- названия и проверенные описания 13 текущих проектов переведены на RU / EN / 中文;
- новый публичный репозиторий появится после обновления серверного кэша, даже до добавления отдельного перевода.

В интерфейсе показываются название, описание, основной язык, дата обновления и ссылка на репозиторий. Секретный GitHub-токен не требуется и не передаётся во frontend.

## Установка

Распакуйте новый архив отдельно от `/opt/logicpulse`, затем выполните:

```bash
bash /root/LogicPulse_Server_v1.2.0/scripts/upgrade-living-pulse.sh /opt/logicpulse
```

Если архив распакован в другую временную папку, укажите фактический путь к скрипту. Установщик создаёт резервную копию и дамп PostgreSQL, собирает frontend, пересобирает backend и проверяет `/api/projects` перед завершением.

## Проверка

```bash
cd /opt/logicpulse
bash scripts/check.sh
curl -fsS https://logicpulse.ru/api/projects | python3 -m json.tool
docker compose logs --since=10m --tail=80 backend nginx
```

В ответе `/api/projects` должны присутствовать:

- `items` — список публичных репозиториев;
- `source` — `github`, `cache` или `snapshot`;
- `profile_url` — профиль основателя.

Откройте `https://logicpulse.ru/#work`, выполните `Ctrl+F5` и проверьте русский, английский и китайский языки.

## Обновление GitHub

После публикации нового публичного репозитория он появится на сайте не позднее чем через 30 минут после следующего обращения. Приватные репозитории не показываются. Чтобы скрыть проект с сайта, сделайте его приватным или добавьте серверное правило фильтрации в следующем обновлении.
