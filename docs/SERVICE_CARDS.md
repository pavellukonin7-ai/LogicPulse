# Карточки услуг: цены, сроки, состав работ и условия

Дополнение к LogicPulse 1.2.0 от 30.09.2026. Установка поверх текущего проекта,
включая уже установленное «Запомнить меня на 30 дней».

## Что исправлено

Ранее главная страница выводила только название и описание услуги. Цена
появлялась только после выбора услуги в форме заявки. Теперь карточка показывает:

- краткое описание с сохранением переносов строк;
- маркированный список «В стоимость входит»;
- диапазон цены или «По запросу», если цены не одобрены;
- срок выполнения;
- публичные условия под ценой;
- индивидуальный текст кнопки перехода к заявке.

Общие условия размещены под каталогом. В редактор добавлены поля для всех
новых данных и пять шаблонов с текстами и диапазонами из обсуждения.
Шаблоны заполняют только форму; до нажатия «Сохранить» в БД ничего не меняется.
При применении шаблона подтверждение цен снимается и внутренняя заметка очищается,
чтобы новая цена не была опубликована по старой калькуляции.

«Объём, сроки и себестоимость» — закрытая административная заметка.
Она не передаётся в публичном API. Срок для клиента вводится в отдельное поле
«Срок выполнения», публичные ограничения — в «Условия под ценой».

## Установка

Заново скачайте актуальный `LogicPulse_Server_v1.2.0.zip` в Downloads.
В Windows PowerShell:

```powershell
scp -i "$env:USERPROFILE\.ssh\logicpulse_root_ed25519" "$env:USERPROFILE\Downloads\LogicPulse_Server_v1.2.0.zip" root@185.125.218.116:/root/
```

В терминале VPS под root:

```bash
python3 -m zipfile -e /root/LogicPulse_Server_v1.2.0.zip /root/logicpulse-cards-update
bash /root/logicpulse-cards-update/LogicPulse_Server_v1.2.0/scripts/upgrade-service-cards.sh /opt/logicpulse
```

Скрипт проверяет хеши изменяемых исходников и останавливается при неизвестных
локальных правках. Затем создаёт дамп БД и архив прежних файлов, собирает frontend
и образ до замены, пересоздаёт только backend, публикует сайт и проверяет сервисы.
При ошибке после начала замены восстанавливает прежние файлы и образ backend.
Возможен короткий перерыв API при пересоздании backend.

В БД добавляется только таблица `lp_service_details`. Старые услуги, идентификаторы,
заявки, аккаунты, сеансы и их связи сохраняются. Автоматического заполнения или
публикации цен нет. `.env`, Compose, Nginx, Xray и авторизация не меняются;
pgAdmin и Registry не включаются. Старый telegram-worker продолжает работу.

## Как заполнить пять услуг

1. После установки откройте `/admin.html` и нажмите Ctrl+F5.
2. Выберите «Редактировать» у существующей услуги.
3. Выберите подходящий «Шаблон услуги LogicPulse» и нажмите «Заполнить поля по шаблону».
4. Проверьте краткое описание, пункты работ, срок, условия, кнопку и цены.
   Название и slug существующей услуги при применении шаблона не заменяются.
5. В закрытой заметке укажите согласованные объём, срок и расчёт. Например,
   для сайта: «До 7 страниц; 3–5 недель; трудоёмкость 50–90 часов;
   расчётная коммерческая ставка 3500 ₽/час. НПД и постоянные расходы учтены
   в модели дохода; AI, хостинг и лицензии оплачиваются отдельно».
   Используйте этот текст только после проверки применимости к своему предложению.
6. Включите «Цены проверены и разрешены к публикации», оставьте «Показывать на сайте».
7. Нажмите «Сохранить услугу» и обновите главную страницу.
8. Повторите для остальных услуг.

| Шаблон | Цена, ₽ | Срок | Оценка часов для внутренней проверки |
|---|---:|---|---:|
| Сайт компании | 175 000–315 000 | 3–5 недель | 50–90 |
| AI-ассистент | 210 000–350 000 | 4–6 недель | 60–100 |
| Автоматизация | 105 000–210 000 | 2–4 недели | 30–60 |
| Интеграция API | 70 000–140 000 | 2–3 недели | 20–40 |
| Внутренняя система | 420 000–700 000 | 7–12 недель | 120–200 |

Цены и часы — предварительная модель для описанного объёма. Само наличие
шаблона не подтверждает себестоимость конкретного проекта или рыночный спрос.

## Проверки и ограничения

47 тестов API прошли: чтение старых услуг без дополнительных данных, запись и
редактирование новых полей, их очистка, сохранение новых полей при запросе старого
клиента, скрытие неподтверждённых цен, отсутствие внутренней заметки в публичном
ответе, права доступа, лимиты длины, сохранение заявок после удаления услуги.
В прогон также включены авторизация, 30-дневные сеансы и прежние проверки API.
Тестовая БД — SQLite. Сборка Vite и синтаксис Bash проверены; Docker-деплой и
визуальная приёмка на настоящем сервере выполняются владельцем.

Для ручного отката используйте архив и `.image-id`, напечатанные установщиком:

```bash
cd /opt/logicpulse
lp_backup=/root/logicpulse-before-cards-YYYYMMDDTHHMMSSZ.tar.gz
tar -xzf "$lp_backup" -C /opt/logicpulse
lp_image_tag="$(docker compose config --format json | python3 -c 'import json,sys; print(json.load(sys.stdin)["services"]["backend"]["image"])')"
docker tag "$(cat "$lp_backup.image-id")" "$lp_image_tag"
docker compose up -d --no-deps --force-recreate --wait --wait-timeout 180 backend
```

Подставьте реальный путь резервного архива. Дополнительная таблица при откате
не удаляется: прежний код её не использует. Записи услуг и заявки не откатываются
автоматически из дампа, чтобы не потерять новые обращения.
