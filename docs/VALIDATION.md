# Проверка версии 1.1.0 — 29 сентября 2026

## Выполнено в среде подготовки

- `npm run build`: Vite 7.3.6, успешно. Сборка включает CSS/JS с хешами и локальный Swagger UI.
- `python -m pytest -q`: 12 успешных тестов API на изолированной SQLite.
- Chromium: пять услуг созданы действиями в Swagger UI (POST /api/services → 201).
- Там же GET /api/services вернул 5 услуг; несогласованные цены в публичном ответе скрыты.
- Открыта собранная главная страница, выбрана услуга AI-ассистентов.
- Заполнена тестовая форма, нажат «Отправить заявку», POST /api/requests → 201.
- В браузере видно «Заявка отправлена!». Проверено фактическое сохранение выбранной услуги,
  email и текста через административный GET.
- Повторная отправка одинакового request_id создаёт одну запись; изменение тела с прежним ID → 409.
- Ошибки валидации → 422; отсутствие ключа администратора → 401.
- При симуляции ответа 503 текст остаётся в форме, ложного сообщения об успехе нет.
- Собранные CSS и JS вернули 200 с верным Content-Type, 404 нет, ошибок JavaScript нет.
- Проверены desktop 1440 px и mobile 390 px; горизонтального переполнения нет, меню работает.
- Compose YAML разобран, прежние тома сохранены; postgres имеет alias db.
- Shell-скрипты проверены bash -n. Dockerfile проверен на доступ непривилегированного app к исходникам.
