# Проверка обновления 1.1.3

Дата: 30 сентября 2026. Это дополнение к ранее проверенной версии 1.1.2.

Локально выполнены 15 unittest-тестов, все прошли:

```bash
python3 -m unittest discover -s backend/tests -p test_server_proxy.py -v
```

Проверены сохранение параметров провайдера без изменения оригинала, отсутствие
внешних слушающих портов и прямого fallback, ограничение на api.telegram.org:443,
отказ от отключённой TLS-проверки и неподдерживаемых профилей, проверка SHA256,
права 600 при записи, восстановление worker при ошибке, проверка Windows перед
откатом и восстановление конфигурации при неудачном переключении.

Проверки управления службами используют mock: они проверяют логику и порядок
действий, не имитируют успешное подключение к реальному провайдеру.
Shell-синтаксис upgrade-server-proxy.sh проверен bash -n.
Синтаксис systemd unit/drop-in проверен systemd-analyze verify с подстановкой
существующего локального исполняемого файла; это не тест службы Xray.

На удалённом VPS установщик ещё не запускался из этой среды. Загрузка бинарника,
его запуск с LoadCredential, доступ к внешнему VLESS-серверу, реальный getMe,
получение заявки без Windows-туннеля и перезагрузка требуют проверки на VPS.
Установщик включает сетевые проверки до объявления успешного переключения.

В обновлении не менялись backend, frontend, Dockerfile, Compose, .env.example,
модели БД и существующие установщики. Их повторная сборка не требуется.
